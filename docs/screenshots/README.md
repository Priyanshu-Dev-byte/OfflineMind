# OfflineMind - Screenshots & Submission Media Guide

Place the captured application screenshots here for your **Snapdragon AI Lab Build & Present Challenge** submission.

### Recommended Screenshots:
1. `01_dashboard_npu_active.png`: Main interface showing the green **⚡ Snapdragon NPU (QNN)** badge in the top right and sidebar.
2. `02_audio_recording.png`: Audio waveform player with live microphone recording or imported lecture file.
3. `03_structured_note_editor.png`: Note editor displaying the generated Title, Executive Summary, Key Takeaways, and Action Items.
4. `04_sqlite_search_library.png`: Notes library showing instant keyword search and tag filtering across multiple notes.
5. `05_pdf_export.png`: Preview of the exported PDF document with styled summary boxes and checkboxes.
6. `06_benchmark_results.png`: Benchmark execution tab showing latency and RTF metrics.
